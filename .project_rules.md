# Project Rules: Vanilla SSG Standard

## 1. Architecture & Stack Mandates
- **Technology Stack**: Vite + Vanilla JavaScript (ES6 Modules) + Modular Plain CSS.
- **Strictly Prohibited**: No React, Vue, Svelte, Tailwind CSS, Bootstrap, or heavy third-party UI libraries.
- **200-Line Limit**: Every JavaScript module (`.js`) and CSS stylesheet (`.css`) must strictly remain under 200 lines. Proactively modularize before reaching 180 lines.
- **Static Multi-Page Output**: All top-level routes and dynamic collection items must be pre-rendered as static HTML files to guarantee zero-JS crawling for search engines and Google AdSense verification.

## 2. AdSense & SEO Guidelines
- **Zero Layout Shifts (CLS < 0.05)**: All media, banners, and dynamic slots must define explicit minimum dimensions or CSS aspect ratios.
- **Semantic HTML**: Always use landmark elements (`main`, `nav`, `header`, `footer`, `article`, `section`) with proper ARIA labels.
- **Structured Data**: Include valid JSON-LD schema on all content and landing pages.
- **Mandatory Trust Pages**: Keep Privacy Policy, Terms of Service, About, and Contact accessible in both navigation and footer.

## 3. Code Quality & Modularity
- Zero console logs and dead code in production bundles.
- Centralize design tokens in CSS custom properties.
- Use lightweight ES module patterns (event bus, singleton managers) instead of monolithic state machines.
