About the Architecture

Returning to foundational web principles without losing modern developer ergonomics.

Modern frontend engineering has drifted toward extreme complexity. Websites that are primarily textual or content-focused often ship hundreds of kilobytes of framework runtimes, resulting in hydration delays, fragile build pipelines, and degraded Core Web Vitals.

VanillaSSG pairs Vite's lightning-fast development server with plain ES6 modules and custom Node pre-render scripts. The output is pure static HTML that can be hosted anywhere, cached forever, and indexed instantly by search engines.

Core Tenets

  • Static First: Content must exist directly in HTML without requiring JavaScript execution.
  • Sub-200-Line Limit: Every single file stays under 200 lines to guarantee modularity and readability.
  • Zero Lock-in: No proprietary template syntax or heavy framework plugins.
